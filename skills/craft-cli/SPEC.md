# Craft CLI skill contract

This portable workflow skill helps agents inspect, prepare, and publish Craft
releases. Keep the runtime guide inline; extra scripts or routed references are
unnecessary for this command-oriented workflow. Only SKILL.md is embedded and
installed. Setup substitutes the actual binary/package version.

Activate for Craft release/configuration/workspace/artifact/changelog requests.
Do not activate for general Sentry issue investigation, app compilation, or
unrelated registry work. Preserve existing authorization, Git work, credential
privacy, and checks required by Craft configuration.

Maintain examples against src/commands and getting-started/release docs. Validate
frontmatter, version embedding, detected-agent-only installation, persistent
opt-out, managed-file protection, dry-run, and native/npm portability. Do not
store credentials, user data, or private release information as examples.
