# Versioning

Craft answers two questions on every release: _what is the next version?_ and _where does that version need to be written?_

## Version format

Craft supports [semantic versioning (semver)](https://semver.org)-like versions:

```txt
<major>.<minor>.<patch>(-<prerelease>)?(-<build>)?
```
